# Entrance Hall PBR benchmark

Five deterministic procedural texture sets generated and embedded in the existing floor_01.glb meshes, preserving all mesh names and authored geometry. The material textures include base color, normal and packed metallic-roughness images.

Modified meshes: {"mahogany": 98, "dark_marble": 12, "forest_damask": 23, "aged_plaster": 1, "antique_brass": 137}

**Limitations:** procedural textures are not photographic scans; texture repetitions and UV seams require visual inspection. No new real-time indirect lighting was introduced. Stair physics remains uncertified. GPU performance and live browser rendering remain unverified. The original .haunt was not edited.
