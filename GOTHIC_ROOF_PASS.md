# Gothic Revival roof direction

User-selected default Forge ornamentation: intricate, eerie Gothic Revival. Preserves each blueprint’s original roof type, footprint, and rise. Adds reusable iron cresting, stone finials, and pointed dormer silhouettes. The dormers in this pass are decorative only, not usable windows or watertight structural dormers. This pass does not yet solve complex valleys or roof drainage and has not been browser-visually approved.

Next passes: ask the user for architectural material preferences, then interior furnishing preferences before implementing each.
