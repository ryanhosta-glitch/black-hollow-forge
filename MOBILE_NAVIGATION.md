# Black Hollow Forge — Mobile Page Navigation

A persistent **☰ Forge Pages** menu was added to all 12 HTML pages. It appears at the top right on desktop and bottom right on phones, with touch-friendly links. It switches among Estate Viewer, Furnishings, Room Intelligence, Story Playtest, First-Person Walk Test and stair inspectors.

Navigation uses relative URLs, so it works on GitHub Pages under `/black-hollow-forge/`. The previous architectural files and assets are preserved unchanged. First-person WASD/pointer lock still requires a keyboard/mouse; this update does not invent mobile movement controls.
