# Black Hollow Forge — Touch Walk Controls

This release adds touchscreen input to `walktest.html` while preserving the desktop WASD/mouse controls and every other Forge HTML page.

On a touch device: move with the bottom-left virtual joystick, drag the right half of the scene to look, tap **E · Use** to interact with nearby doors, tap **Map** for room inspection, and hold **Reverse** to walk backward. A stair route selected in the main HUD can be progressed with forward joystick movement.

The route remains a guided architectural test—not physically certified stair collision. Textures, architecture, and `.haunt` source files are unchanged.

This is a code/syntax-tested release, not a device-tested release. For testing, deploy to GitHub Pages and open `/walktest.html` on your phone.
