# Black Hollow Forge — Spiral Geometry Prototype

This checkpoint adds actual exported GLB spiral stair candidates for the four screened stairwells. It does **not** silently substitute a spiral for a student-authored switchback. Each model is a separate hypothetical option for inspection.

The candidates have 3D wood treads, central columns, and simple balusters. They satisfy the conservative bounding-box envelope, not complete room-space geometry. The gold endpoint markers are visual diagnostics, **not landings**.

**No game-ready staircase is certified**. Door approaches, upper/lower landings, slab cuts, headroom through the real mesh, and player collision must still be designed and tested. See the inspector and `navigation/spiral_geometry_prototypes.json`.

Open `spiral_geometry_inspector.html` from the Forge Pages menu after GitHub deployment. On phones, drag to rotate and pinch to zoom. Original `.haunt` is byte-identical.
