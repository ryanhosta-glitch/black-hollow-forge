# Serpent Spiral approach geometry

Created real upper and lower approach platform GLB meshes, separate from the existing stair model. They bridge the 0.779 m projected gap from each authored doorway to the spiral envelope, using a 0.76 m wide walkway. This is inspection-only and not gameplay certified. The tread-entry angle, upper slab opening, head clearance, and capsule collision remain unresolved. No original blueprint or building geometry was modified. Open `serpent_spiral_approaches.html`.
