# Gothic fixture preview pass

Adds procedural Victorian chandeliers, wall sconces, candelabra and decorative fireplaces to the estate viewer. The objects are cosmetic preview overlays based on room names and footprints. They are deliberately not baked into exported GLBs and have no physical collision. Lighting still comes from the existing bounded room-light pool; individual fixture flames do not each receive a dynamic light, to protect mobile performance.

Use the Fixtures ON/OFF button to compare the model with and without fixtures. Generated designs are stylized and require browser verification, especially for attachment to actual walls and student furniture clearance. Student `.haunt` sources are unchanged.
