# Grand Entrance Hall Visual Benchmark

This pass **modifies the real exported ground-floor GLB** with 202 additional named decorative meshes restricted to the Grand Entrance Hall, including a ceiling medallion, carved-style coffering, chandelier with crystal drops, high-mounted sconces, and floor inlays. Original floor model nodes and the student `.haunt` source are preserved. The generated geometry is visual-only, not new player-collision objects. Rendering on a live browser and light emission are not verified; candle flames are decorative geometry rather than powered light sources.

Open the Estate Viewer and select the ground-floor model to inspect. The upgrade is not a standalone mockup.
